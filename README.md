# Simulador Epidemiológico SIR en JavaFX

Proyecto académico que simula la propagación de una epidemia usando el modelo SIR.
Incluye interfaz gráfica con JavaFX, arquitectura MVC y patrones de diseño.

## Requisitos
- Java 17+
- JavaFX SDK
- MySQL (para login y persistencia)

## Ejecución
1. Clonar el repositorio
2. Compilar con Maven/Gradle
3. Ejecutar `MainApp.java`
